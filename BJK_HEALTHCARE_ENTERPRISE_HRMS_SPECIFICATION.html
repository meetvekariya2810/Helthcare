1. System Overview & Technology Stack

The BJK Healthcare HRMS is fully integrated into the existing BJK Healthcare Digital Brain. It operates on a unified single database layer (bjk_healthcare on MongoDB Atlas) with zero duplicate authentication, user records, or audit subsystems.

  • Frontend: React 18, Vite 5, Tailwind CSS, React Router v6, Lucide React, Recharts.
  • Backend: Node.js, Express.js, JWT, bcryptjs, Helmet, CORS, PDFKit streaming engine.
  • Database: MongoDB Atlas with indexed Mongoose schemas and strict relational references.
  • Security & RBAC: Granular permissions per role, bcrypt salted password hashing, 21 CFR Part 11 electronic audit logs.

3. Implemented PDF Document Generation Engine

The platform features a dedicated server-side streaming PDF generator (pdfService.js) built with pdfkit. Documents are streamed directly over HTTP as binary attachments with verification hashes and automatic audit trail records.

  • Salary Payslips: GET /api/hrms/payroll/:id/pdf — Comprehensive monthly earnings, statutory deductions (PF, ESI, PT, TDS), attendance statistics, and net pay in words.
  • Training & GMP Certificates: GET /api/hrms/training/enrollments/:id/certificate-pdf — Landscape certificate with decorative borders, assessment score, valid-until date, and QA director stamp.
  • Offer Letters: GET /api/hrms/recruitment/candidates/:id/offer-pdf — Formal appointment letters with Annexure A CTC breakdown, plant location, and confidentiality clauses.
  • Experience Certificates: GET /api/hrms/employees/:id/experience-pdf — Service tenure verification, designation, and conduct certification.
  • Statutory Reports: GET /api/hrms/reports/export?type=...&format=pdf — Form 25 Attendance Muster Roll and Employee Master directories.

4. Role-Based Access Control (RBAC)

Role Module Authorization Scope Confidentiality Safeguards
SUPER_ADMIN / DIRECTOR All system modules, analytics, audit logs, and configuration. Full system oversight, executive sign-off authority.
HR_ADMIN / HR_MANAGER Employees, onboarding, leave approvals, shifts, recruitment, training. Restricted from unmasked salary data unless authorized.
PAYROLL_ADMIN / FINANCE Payroll calculation, salary disbursement, expense claims. Strictly isolated financial view; creates audit trail on changes.
DEPARTMENT_MANAGER Subordinate team roster, attendance corrections, shift swaps, reviews. Scoped strictly to reporting team members.
EMPLOYEE Employee Self Service (ESS): check in/out, view own payslip, apply leave. Zero visibility into peers' personal or salary information.
